# 配達ペースメーカー（ラウンドタイマー）仕様書

Android向けのオフラインPWA。配達時間と配達個数から1ラウンドの時間を出し、ラウンドごとのカウントダウンで配達ペースを保つためのタイマー。

`mock-reference.html` はデザインツールで作ったモックで、レイアウト・色・文字サイズ・ロジックの参考資料。専用ランタイム（support.js / DCLogic）に依存しているため、そのままでは動かない。中身を読んで同じ見た目・動作で作り直すこと。

## 技術要件
- 単体で動くPWA（HTML/CSS/JS。フレームワークは任意だが軽量に）
- manifest + service workerで全ファイルをキャッシュし、完全オフラインで起動できること
- ホーム画面に追加して全画面（standalone）・縦向き固定で動作
- フォントは同梱する（Inter と Noto Sans JP。日本語は使う文字だけにサブセット化）。CDNは使わない
- 時間計測は開始時刻との差分で計算する（setIntervalのカウントに頼らない）。表示更新は100〜250ms間隔
- 計測中は Screen Wake Lock API で画面を点けたままにする。一時停止・終了で解除し、アプリに戻ったら再取得する
- ラウンドの切り替わりと超過突入時は navigator.vibrate で振動させる
- 前回の設定（時間・分・個数）を localStorage に保存し、次回起動時に復元する
- デプロイ先はHTTPSの静的ホスティング（GitHub Pages / Cloudflare Pages など）

## 画面1：設定
- 入力：配達時間（時間・分）、配達個数（初期値 4時間0分・120個、以降は前回値）
- 表示：1ラウンドあたりの時間（= 総時間 ÷ 個数）、「× Nラウンド」
- 表示：「今スタートすると HH:MM → HH:MM に終了」（現在時刻と終了時刻をリアルタイム更新、1行で折り返さない）
- スタートボタン（時間0や個数0のときは無効）

## 画面2：計測
上から順に：
1. ヘッダー：左に「PACE MAKER」、右に「一時停止中」バッジ（停止時のみ）とロックボタン
2. ラウンドカード（左右2分割）：左「現在 / 総数」ラベル + 現在ラウンド番号（アクセント色）、右「残り」+ 残りラウンド数。3桁でもはみ出さないこと
3. タイマー：ラベル「次のラウンドまで（1ラウンド m:ss）」+ 大きなカウントダウン。残り10秒で警告色
4. 進捗バー（現在ラウンドの経過割合）
5. 「経過 h:mm:ss」「全体残り h:mm:ss」を1行で
6. 枠付きカード：左に「終了予定 HH:MM」（大・アクセント色）、右に「現在時刻 HH:MM」
7. 下部：一時停止/再開ボタン、終了ボタン（設定画面に戻る）

### ラウンド進行
- 完了ボタンはなし。1ラウンドの時間が切れたら自動で次のラウンドへ進み、振動（300-150-300ms）
- 一時停止中は全カウントが止まり、終了予定はその分後ろにずれる

### 超過モード
- 全ラウンドの時間が終わったら長めに振動（600-200-600-200-600ms）し、計測を続けたまま超過モードに入る
- ラウンドカードの数字は両方「超過」（警告色）に変わる
- タイマーのラベルは「超過時間」になり、「+m:ss」でカウントアップ（1時間超えは「+h:mm:ss」で、文字を小さくしてはみ出さない）
- 進捗バーは警告色で100%
- 「全体残り」は「+超過時間」を警告色で表示。「終了予定」は本来の終了時刻のまま固定

### 画面ロック（誤タッチ防止）
- ロックボタンで画面全体を透明なカバーで覆い、タッチを無効化する。画面は暗くしない
- ロック中はヘッダー右のボタンが「ロック中」表示（アクセント色の枠）に変わる
- そのボタンを約1.2秒長押しで解除。押している間はボタン内が下から埋まる進捗表示
- 長押しメニューやテキスト選択が出ないようにする

## デザイン
- テーマ：マトリックス風（黒緑の背景＋蛍光グリーン）。文字にうっすら緑の発光（text-shadow: 0 0 6px rgba(0,255,65,0.35)）、ごく薄い走査線をオーバーレイ（タッチを妨げない）
- フォント：`-apple-system, 'SF Pro Display', 'Inter', 'Hiragino Sans', 'Noto Sans JP', sans-serif`。数字は font-variant-numeric: tabular-nums で幅を揃えてガタつかせない
- 色
  - 背景 #020A04 / カード #061A0C / 区切り線 #0F3D1E / 枠線 #145A2A
  - 文字 #C4FFD2 / 補助文字・ラベル #46C66A
  - アクセント #00FF41（ボタン上の文字は #001A08）
  - 警告（残り10秒・超過）#FFB000
- 文字サイズの目安（幅390px基準）：タイマー108px（超過時88px / 1時間超64px）、ラウンド数字72px（「超過」は56px）、終了予定44px、現在時刻30px、経過・全体残り26px、ラベル15〜16px
